# Match individual sites to water quality standards

Use a site-group lookup table to determine which WQS group each site is
in.

## Usage

``` r
match_sites_to_WQS_groups(wq_data, site_group)
```

## Arguments

- wq_data:

  Data frame

- site_group:

  Site-group lookup table as an R data.frame object

## Value

Data frame with site_group lookup table information
